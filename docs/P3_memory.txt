· Regex: Use POSIX regex (regcomp, regexec) or PCRE2 for rule extraction. For simple [NEW_RULE: ...] patterns, you can also write a hand-rolled parser to avoid regex overhead.
· Threading: Use POSIX threads (pthread) with mutexes for thread safety.
· String Handling: Implement dynamic string buffers (e.g., strdup, realloc) for state and rule manipulation.

· For JSON, consider a streaming parser if the file grows large, but 16 MB is manageable with cJSON.
